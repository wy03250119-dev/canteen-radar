# 🍚 食堂雷达 · 校园食堂点评推荐

> 帮大学生解决「食堂吃什么」的决策困境：发现新菜品、避开踩雷窗口。
> 纯静态前端应用，无构建依赖，双击 `index.html` 即可运行，任意静态托管均可部署。

## 产品功能

| 模块 | 说明 |
| --- | --- |
| 🏠 首页 | 时段问候、全校统计、今日人气王、人气 TOP8、新菜速递、食堂卡片 |
| 🏫 食堂 | 11 个食堂（大学城校区 + 南校区 双校区）/ 43 个窗口 / 92 道菜品；校区、营业中、评分、距离筛选 |
| 🍽️ 菜品详情 | 综合评分 + 口味/分量/性价比/出餐速度四维评分、近7天口碑趋势、避雷/安利标记、写点评 |
| 🏆 榜单 | 人气榜 / 评分榜 / 口碑上升榜（近7天趋势） |
| 🚫 避雷榜 | 踩雷菜品 TOP10、避雷窗口、学长学姐避雷心得 |
| 🤖 AI 推荐 | 结合评分与个人口味偏好的"摇一摇"决策工具 |
| ✍️ 点评系统 | 星级 + 标签 + 文字点评、点赞、删除，实时刷新菜品评分 |
| 👤 我的 | 贡献值体系、口味偏好、我的点评/避雷清单 |
| 🔍 搜索 | 菜品/窗口/食堂全文检索 |
| 📶 实时排队指数 | 按当前时间 + 窗口高峰时段动态模拟拥挤度 |

## 技术说明

- 原生 HTML/CSS/JS 单页应用（hash 路由 + 事件委托 + localStorage），零依赖、零构建
- 移动端优先（App 化底部导航 / 底部抽屉 / Toast），桌面端居中卡片布局
- 用户产生的点评、避雷、安利、偏好均保存在浏览器 localStorage
